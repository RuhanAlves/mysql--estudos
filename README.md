# mysql--estudos

#🗄️ Estudos de MySQL

Repositório criado para registrar minha evolução nos estudos de Banco de Dados e SQL durante minha formação em Técnico em Informática no COTEMIG.

##📚 Sobre

Este repositório reúne atividades práticas desenvolvidas para estudar e aplicar conceitos de SQL e MySQL, desde a criação e estruturação de bancos de dados até a construção de consultas envolvendo diferentes tabelas.

Os exercícios são desenvolvidos com o objetivo de reforçar a lógica de consultas e compreender, na prática, como os dados são organizados e relacionados em um banco de dados relacional.

##🛠️ Tecnologias
MySQL
SQL

##📂 Atividades

###🎮 01 — Agregação e agrupamento de dados

###🕹️ 02 — Relacionamento entre tabelas

Atividade prática utilizando um sistema fictício de jogadores, servidores, itens e penalidades.

Conteúdos praticados
